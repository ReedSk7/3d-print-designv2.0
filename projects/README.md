# Legacy Project Archive

The folders in this directory predate Parametric Part Workbench v3. They are
retained as source/notes history and migration evidence, not as active v3
specifications or proof of physical fit.

Do not infer v3 status from legacy `PASS`, `verified`, export, preview, or mesh
language. Follow `docs/rebuild/MIGRATION_MAP.md` before salvaging an individual
file. Routine generated outputs were removed from the active rebuild branch and
remain recoverable in Git history.
