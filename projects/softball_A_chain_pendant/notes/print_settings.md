# Print Settings

Recommended printer: Bambu Lab P2S with AMS

Recommended material:
- PLA for easiest color changes and crisp raised detail.
- PETG for a tougher bag tag or keychain pendant.

Recommended slicer settings:
- Layer height: 0.2 mm
- Walls: 3 to 4
- Infill: 15% to 25%
- Top/bottom shells: at least 5 top and 4 bottom layers
- Supports: none preferred
- Orientation: print flat on the bed, face up
- Brim: optional for PETG or if the pendant edge lifts

AMS color order:
1. Black - base, bail, rim, stitch shadows, A outline
2. Yellow - softball face
3. Red - raised A and stitches
4. White - optional highlights

Purge waste reduction:
- Print more than one pendant at a time when using AMS.
- Keep the optional white highlight disabled if you want fewer color swaps.
- Use the same color order across multiple copies.
- In Bambu Studio, import multicolor STLs as parts of one object so all color bodies remain aligned.

Strength notes:
- Use 4 walls for keychain or bag clip use.
- PETG is preferred if the bail will see repeated pulling.
- Do not scale below the included small version unless you re-check the bail opening and stitch width.
