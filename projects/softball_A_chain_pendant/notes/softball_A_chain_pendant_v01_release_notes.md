# softball_A_chain_pendant v01 Release Notes

Initial release candidate for a softball-style A pendant with standard and oversized bail options. Revised to better match the cleaner user-supplied Meshy silhouette while rebuilding the geometry cleanly in OpenSCAD.

Use the single-color STL for easiest printing. Use the multicolor parts for AMS printing after importing them as aligned parts of one object in Bambu Studio.
