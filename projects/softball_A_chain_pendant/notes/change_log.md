# Change Log

## v01

- Created original softball-style pendant model from visual references.
- Added flat-back medallion body with raised black rim.
- Added chunky fused top bail with standard and oversized variants.
- Added yellow softball face, raised red stitch geometry, and decorative raised A with black outline.
- Added optional white highlight bodies for AMS use.
- Added large and 75 mm small size variants.

- Treated user-provided Meshy/3MF outputs as supporting rough meshes.
- Revised the fallback A into a taller swash-style printable emblem closer to the cleaner rough mesh silhouette.
- Kept white highlights optional and out of the default full assembly.
- Added numeric OpenSCAD export selectors for reliable scripted STL exports.
