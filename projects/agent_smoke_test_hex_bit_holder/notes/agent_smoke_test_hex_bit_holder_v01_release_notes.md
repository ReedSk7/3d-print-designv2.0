## What Changed

Initial smoke-test version of a six-pocket 1/4 inch hex bit holder.

## Known Assumptions

- 6.35 mm nominal bit size.
- 0.35 mm pocket clearance.
- PETG material recommendation.
- Bambu Lab P2S printer target.

## Low-Confidence Zones

- actual bit brand fit
- actual screw head fit
- horizontal screw hole roundness

## Print Instructions

Print flat with the bottom/base face on the bed and pockets opening upward. No supports preferred.
