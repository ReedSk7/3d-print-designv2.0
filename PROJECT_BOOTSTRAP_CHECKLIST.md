# Project Bootstrap Checklist

Required reading before modeling begins.

Check every item before geometry work starts. If critical data is missing, create measurement notes and a measurement checklist instead of guessing final fit geometry.

- [ ] project stem chosen
- [ ] project stem confirmed lowercase snake_case
- [ ] version number selected
- [ ] task mode selected
- [ ] target part defined
- [ ] reused parts defined
- [ ] not-modeled items defined
- [ ] references categorized as measured/public/paid/supporting
- [ ] authoritative references identified
- [ ] supporting references identified
- [ ] anchor dimensions recorded
- [ ] measured dimensions separated from inferred dimensions
- [ ] protected interfaces defined
- [ ] low-confidence zones listed
- [ ] output artifact plan selected
- [ ] required previews selected
- [ ] printer bed-fit considered
- [ ] printability risks considered before modeling

Do not begin OpenSCAD modeling until all required bootstrap items are complete.
