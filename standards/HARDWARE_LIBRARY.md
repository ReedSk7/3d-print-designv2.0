# Hardware Library Starter

This file is a starter reference, not a final engineering authority. Measured dimensions override placeholders.

## Common Clearance Placeholders

- M3 clearance starter: 3.4 mm
- M4 clearance starter: 4.5 mm
- M5 clearance starter: 5.5 mm

## Insert Placeholders

- Heat-set insert sizes vary by brand and profile.
- Start from the actual supplier spec when available.
- If no spec exists, measure the real insert before locking dimensions.

## Magnets

- Common starter sizes: 6x2 mm, 8x3 mm, 10x3 mm
- Add retention features or adhesive plan as needed.
- Measure the actual magnet batch before finalizing pockets.

## Bearings and Rods

- Common rod references: 3 mm, 5 mm, 8 mm
- Common bearing families may need manufacturer-specific fits.
- Measure rod diameter and seat behavior before finalizing interface geometry.

## General FDM Fit Starters

- Snug fit starter: begin with a very small clearance and expect printer-specific tuning.
- Sliding fit starter: allow more clearance than a snug fit so motion is reliable after printing.
- Friction fit starter: start tighter than a sliding fit, then tune from test prints.
- Holes usually print undersized relative to nominal CAD.
- Sliding fits typically need clearance beyond nominal.
- Press fits and snap fits need printer- and material-specific tuning.
- Printer and material tuning beat placeholders.
- Use these as starting points only; measured test-fit results win.
