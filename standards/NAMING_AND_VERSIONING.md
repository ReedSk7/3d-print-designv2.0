# Naming and Versioning

- Use lowercase snake_case for project stems and filenames.
- Keep one project stem per part or design.
- Use the `_vNN` version suffix, for example `clip_bracket_v03.scad`.
- STL naming should always version-match the SCAD source, for example `clip_bracket_v03.stl`.
- Match preview names to the same version, for example `clip_bracket_v03_iso.png`.
- Notes and manifests should version-match the source and export where applicable.
- Never overwrite prior versions. Create the next version instead.
